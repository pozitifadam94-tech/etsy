PRIVATE SELLER TOOL

STL Niche Research

A research workspace being developed for the owner of GoatDesgnShop to organize STL product niches and compare marketplace observations.

Purpose and current features

The tool records listing links, prices, observation dates and manually collected review counts. It supports niche comparisons, product candidate tracking, CSV imports and JSON backups.

The current version uses manual data entry. Etsy API integration is planned subject to approval and permitted access. It does not claim access to competitors’ private sales or exact search volumes.

Users and data

The application is intended for the shop owner’s personal use. Access will not be sold to other users. Current research records are stored in the user's browser; the application has no account system or shared database.

It does not upload or edit Etsy listings or send emails. Analysis of the owner's sales data may be added with appropriate authorization.
