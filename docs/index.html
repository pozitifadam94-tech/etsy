One daily workspace

The local application uses read-only Etsy OAuth access to synchronize the owner's active listings and paid sales records. It provides sales trends, listing checks, automatic product groups, and observations of listing metadata changes.

Public marketplace observations track permitted listing samples and prices. Suggested searches come from the shop's product groups; they do not claim exact search volumes or access to competitors' private sales.

Personal use. Data on your device.

The app is for the shop owner's personal use; access is not sold. Browser notes can be backed up locally. Etsy credentials and tokens remain in the local Windows user directory and are never included in the static website.

This website hosts the static interface. Live Etsy features require the local application, an approved app, and authorization. The application does not publish, edit or delete listings, send customer messages, or post to social platforms.
